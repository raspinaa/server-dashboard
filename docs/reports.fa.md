# گزارش مدیریتی

بخش «گزارش مدیریتی» جمع منابع موجودی و جزئیات پروژه‌ها، محیط‌ها، Application/سرویس‌ها، سیستم‌عامل‌ها و شبکه‌ها را نشان می‌دهد. نمودارهای CPU، RAM و دیسک مستقل هستند. تعداد ماشین و دیسک، وضعیت گردش کار، کیفیت تکمیل فیلدها و فعالیت‌های ۳۰ روز اخیر نیز نمایش داده می‌شوند. این داده‌ها پایش زنده یا امتیاز سلامت نیستند.

همه پروژه‌های مجاز یا یک پروژه را انتخاب کنید. با انتخاب پروژه، فیلتر محیط فعال می‌شود. پروژه‌ها و ماشین‌های بایگانی در گزارش مدیریتی کنار گذاشته می‌شوند. ردیف‌های بدون ماشین در جزئیات تجمیعی نمایش داده نمی‌شوند؛ تعداد پروژه‌ها و محیط‌ها شامل موارد فعال بدون ماشین هم هست. زمان تهیه گزارش به وقت تهران نمایش داده می‌شود. دکمه تازه‌سازی، آخرین داده پایگاه را دریافت می‌کند.

پایین داشبورد، پروژه خروجی را مستقل انتخاب کنید و موجودی یا فعالیت را به XLSX بگیرید. گزارش همه پروژه‌ها به‌معنی مجوز خروجی همه آنها نیست؛ هر خروجی برای یک پروژه مشخص و با مجوز همان پروژه صادر می‌شود. قالب موجودی همان قالب ورود فعلی با ستون‌های مستقل، دیسک‌های پویا، Subnet و UUID مخفی است؛ نمودارهای مدیریتی وارد workbook موجودی نمی‌شوند. مجوز خروجی رمز مستقل و انتخاب آن پیش‌فرض خاموش است.

در «مرکز خروجی Excel» نیز انتخاب مستقل پروژه اضافه شده است؛ انتخاب جدید، محیط و گزینه‌های حساس فرم را بازنشانی می‌کند. API گزارش: `GET /api/reports/?project=ID&environment=ID`. بدون project همه پروژه‌های مجاز؛ انتخاب environment بدون project خطای اعتبارسنجی می‌دهد. API داده رمز برنمی‌گرداند و خروجی آن cache نمی‌شود.

جدول جزئیات ماشین‌ها، شناسه پایدار و فیلدهای مستقل را با صفحه‌بندی ۵۰تایی برمی‌گرداند. تعداد ستون دیسک در هر صفحه پویا است؛ فایل Excel تعداد ستون مناسب کل پروژه انتخاب‌شده را دارد. API پارامتر `page` نیز می‌پذیرد؛ جمع‌ها همیشه کل نتیجه فیلترشده هستند، نه فقط صفحه جاری.
