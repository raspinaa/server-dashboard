# چارچوب طراحی Infra-HUB

تمام صفحات فارسی و راست‌به‌چپ هستند. فونت Vazirmatn همراه بسته و بدون اتصال اینترنت بارگذاری می‌شود؛ مجوز آن در public/fonts قرار دارد.

رنگ، فاصله و حالت روشن/تیره از متغیرهای design.css گرفته شود. از رنگ مستقیم جدید در هر صفحه پرهیز شود. رنگ آبی برای اقدام اصلی، فیروزه‌ای برای نتیجه موفق، کهربایی برای مورد نیازمند بررسی و قرمز برای شکست است. رنگ تنها نشانه وضعیت نیست؛ متن وضعیت همیشه نمایش داده شود.

عنوان صفحه از SectionHeading، شاخص عددی از MetricCard، نمودار از BarChart/DonutChart و صفحه‌بندی از Pager استفاده کند. نمودارها فقط موجودی ثبت‌شده و منابع تخصیص‌یافته را نشان می‌دهند؛ مصرف زنده یا روند زمانی بدون داده واقعی نمایش داده نشود.

فیلترها بالای جدول، عملیات هر رکورد در همان ردیف و فرم ایجاد/ویرایش به‌صورت بازشونده باشند. جدول بزرگ در سرور صفحه‌بندی شود؛ اندازه پیش‌فرض ۳۰ و گزینه‌ها ۳۰/۵۰/۱۰۰ است. عنوان قابل مرتب‌سازی وضعیت جهت را نشان دهد. در همه محیط‌ها، محیط محور نخست ترتیب موجودی است.

عملیات به مجوز معتبر سمت سرور وابسته است. پنهان‌کردن یا غیرفعال‌کردن دکمه جای بررسی مجوز API را نمی‌گیرد. رمزها در گزارش و رویداد نمایش داده نشوند.

پیش از انتشار، صفحه ورود، نمای کلی، جدول، فرم‌ها و منوی حساب در نمایشگر بزرگ و موبایل، هر دو حالت روشن و تیره، بررسی شوند.
