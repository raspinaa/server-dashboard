# دموی عمومی InfraHub

این پوشه یک سایت ایستا و مستقل است: داده‌ها ساختگی، IPها از محدوده‌های مستندسازی، بدون رمز، API، دیتابیس، احراز هویت واقعی یا storage مرورگر. ویرایش، نظر، جستجو، انتخاب محیط، نمودارهای محاسبه‌شده و خروجی JSON در همین جلسه مرورگر اجرا می‌شوند. ورود Excel، مدیریت دسترسی و ارتقا صرفاً گردش کار را توضیح می‌دهند و سرویس اجرایی ندارند. تغییرات با reload پاک می‌شوند.

اجرای محلی: `python3 -m http.server 8090 --directory demo` از ریشه مخزن. سپس آدرس محلی پورت 8090 را باز کنید.

Workflow در `.github/workflows/demo-pages.yml` فقط همین پوشه را منتشر می‌کند؛ backend، تنظیمات خصوصی و فایل‌های آپلود منتشر نمی‌شوند. URL مورد انتظار: https://raspinaa.github.io/server-dashboard/ . در تنظیمات مخزن، Pages → Source باید GitHub Actions باشد. workflow برای فعال‌سازی خودکار تلاش می‌کند؛ اگر سیاست سازمان/سطح دسترسی اجازه نداد، مدیر مخزن آن را فعال کند و workflow را مجدداً اجرا کند. برای مخزن خصوصی، پلن حساب باید Pages را پشتیبانی کند؛ انتشار عمومی محتوای demo باید مجاز باشد.

آزمون مرورگر پس از `npm ci` در frontend و اجرای وب‌سرور محلی: `NODE_PATH="$PWD/frontend/node_modules" node tests/demo/smoke.cjs`. اگر Chromium سیستم استفاده می‌شود، `DEMO_CHROMIUM=/PATH/TO/chromium` بدهید؛ در غیر این صورت `npx playwright install chromium` در frontend لازم است. آزمون دسکتاپ/موبایل، ویرایش منابع، نظر با کاراکترهای HTML، انتخاب محیط، پیش‌نمایش و خروجی نمایشی را بررسی می‌کند.
